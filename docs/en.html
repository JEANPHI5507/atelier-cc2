Prepare

Your model, in your spools' colours.

Drop an STL, a 3MF or an AI-generated model. The workshop maps each colour to a CANVAS spool, sizes it and picks the best face to lay it on.

  • "Optimise for the CC2": repair, size, position, supports
  • Purge sized for each colour change, no marbling
  • Sliced by OrcaSlicer with the CC2 profiles

Monitor

Every layer, every colour.

The live camera, the part growing in 3D, the current colour and the next ones with their delay. An AI watches the camera and pauses if it sees spaghetti.

  • Notified at the end, then when the plate is cold
  • Timelapse and photo of every print in the gallery
  • A review afterwards: the fix is offered next time

Anywhere

In your pocket. Or on the wall.

An app to install on your phone, over HTTPS and protected by a code. A dashboard for an old tablet, with a cross-section view of the print. Away from home, through Tailscale: no open port.

What it does. What it doesn't.

It does

  • The whole path for a CC2 with CANVAS, tested on a real machine
  • Run on a PC or small home server, no cloud
  • Keep your library, spools, costs and reviews
  • Create parts without CAD: Gridfinity, screws, ornaments with a name…

It doesn't

  • Replace the firmware: it talks to the CC2 the way LAN mode allows
  • Guarantee the future: a firmware update may break a command
  • Run on Windows or macOS: Linux x86-64 for now
  • Come from Elegoo: it's a personal project

Try it

Two minutes, no printer needed.

The simulator starts a virtual CC2 with the workshop: camera, a CANVAS with four spools, prints in fast motion.

# Linux, Python 3.12 and uv
git clone https://github.com/JEANPHI5507/atelier-cc2 && cd atelier-cc2
uv sync && make slicer
uv run cc2 simulateur          # then http://localhost:8788/lab/

# with your CC2 (LAN mode), open to your phone
uv run cc2 --control dash --reseau

Frequently asked questions

How do I print in several colours with the Centauri Carbon 2 CANVAS?

Drop a coloured model (3MF, GLB, OBJ) into the workshop: each colour is mapped to the closest spool loaded in the CANVAS, the purge is sized for each colour change, then OrcaSlicer slices with the CC2 profiles.

Does it need Elegoo's cloud?

No. The workshop talks to the printer over the local network (LAN mode), and the camera AI runs on your own machine: no image leaves your home.

How can I detect a failed print with the CC2 camera?

The workshop analyses one image every 10 seconds with Obico's free model (The Spaghetti Detective). It warns at the slightest doubt, and can pause the print when it is sure.

What does it run on?

A Linux x86-64 PC or small home server, with Python 3.12. You open it from a browser, a phone (installable app) or a tablet. A simulator lets you try it without a printer. The interface is in French for now.

Is it free?

Yes, the code is open source (MIT licence). It is not an Elegoo product: it is a personal project.
