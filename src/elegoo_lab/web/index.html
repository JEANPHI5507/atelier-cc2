Le jour où l'imprimante arrive

Quatre étapes, dans l'ordre. Compte une heure, impressions de test comprises.

1

Connecter l'imprimante

  1. Allume-la et termine l'assistant de l'écran (langue, Wi-Fi ou câble, nivellement automatique).
  2. Sur l'écran : Paramètres → Réseau. Active « LAN Only » (sans lui, l'accès local est fermé).
  3. Note l'adresse IP et le code d'accès affichés, puis saisis-les ici. Ce PC est en … : l'imprimante doit être sur le même réseau.

2

Charger le CANVAS

  1. Place 4 bobines de PLA dans le CANVAS : de préférence 4 couleurs bien différentes (ex. rouge, bleu, vert, jaune) pour lire facilement le test couleur.
  2. Engage chaque filament jusqu'à ce que l'écran affiche la bobine comme chargée (1 à 4, de gauche à droite).
  3. Vérifie dans l'onglet Imprimante → Bobines CANVAS que les 4 apparaissent avec la bonne matière.
3

Imprimer les pièces de test

Dans l'ordre : chaque test valide quelque chose dont le suivant a besoin. Coche ce que tu constates, l'atelier s'en souvient.

4

Régler l'assemblage des pièces découpées

Après le test des chevilles : choisis le jeu du premier trou où la cheville entre à la main, serrée sans forcer. Il sert à toutes les prochaines découpes.

À régler sur l'écran de la CC2

En réseau local, la CC2 n'accepte pas ces commandes (le SDK officiel d'Elegoo les désactive) : fais-les sur l'écran tactile.

  • Mise en origine, déplacer la tête : avant un nettoyage de buse ou un changement de plateau.
  • Décalage Z (première couche) : si le test « Première couche » est trop écrasé ou ne colle pas, par pas de 0,02 mm.
  • Calibrations automatiques (nivellement, vibrations) : après le transport et tous les quelques mois.
  • Charger / décharger un filament hors CANVAS.
  • Reprendre une impression en pause : si le bouton de l'atelier ne répond pas, reprends depuis l'écran.
  • Mise à jour du firmware : seulement pour corriger un problème précis. Depuis la 02.00.02.00, le retour à une version antérieure est bloqué ; la 02.01.00.00 (juillet 2026) ajoute la compensation de résonance de l'axe Z. Après une mise à jour, vérifie l'atelier (pycentauri est figé en 0.9.1).
  • Mode LAN seulement : nécessaire pour l'atelier ; il coupe l'IA et la vidéo à distance d'Elegoo (l'atelier les remplace).

Le téléphone doit être sur le même Wi-Fi que ce PC.

1Certificat de l'atelierune seule fois

Scanne : le fichier se télécharge. Puis Paramètres → Sécurité → Plus de paramètres → Chiffrement et identifiants → Installer un certificat → Certificat CA, choisis atelier-cc2.crt.

Ouvre l'adresse ci-dessous dans Chrome : le fichier se télécharge. Puis Paramètres → Confidentialité et sécurité → Sécurité → Gérer les certificats → Autorités → Importer (ou tape chrome://certificate-manager), choisis atelier-cc2.crt et coche « Faire confiance à ce certificat pour identifier des sites Web ».

Scanne avec l'appareil photo, ouvre dans Safari, Autoriser. Puis Réglages → Profil téléchargé → Installer, et Réglages → Général → Informations → Réglages des certificats : active « Atelier CC2 ».

Il sert seulement à prouver au téléphone que c'est bien ton atelier.

2Ouvrir et installer l'appli

Scanne, saisis le code d'accès (affiché au lancement de cc2 dash --reseau).

Puis le bouton Installer l'appli en haut, ou menu ⋮ → Installer l'application.

Puis Partager → Sur l'écran d'accueil.

Pour le tableau de bord, ouvre l'adresse du tableau (plus bas) puis l'icône d'installation dans la barre d'adresse, ou menu ⋮ → Installer. Maintenant

    Comment c'est sorti ?

    Coche ce que tu vois : l'atelier explique pourquoi et garde la correction pour la prochaine impression de ce modèle.
    Importer depuis un lien

    Marche avec un lien direct vers un STL, 3MF, OBJ, GLB ou un zip, et avec les pages qui donnent ce lien. MakerWorld et Thingiverse demandent d'être connecté : télécharge le fichier puis dépose-le.
    Suivi des impressions

    L'atelier surveille l'imprimante en continu, même sans page ouverte : début, pause, plus de filament, fin (avec une photo), arrêt et erreur.
    Ajouter un texte

    Pour un modèle plat (dessin au trait, plaque). Le texte se place tout seul dans l'espace libre et reste relié au modèle (d'un trait à l'autre, ou par une fine barre) ; il s'imprime avec une deuxième bobine. Un nouveau fichier est créé, l'original reste intact.
    Bobine

    L'atelier retire le filament de chaque impression terminée. Corrige ici si tu as pesé la bobine (sans le support vide, environ 250 g pour une bobine plastique).
